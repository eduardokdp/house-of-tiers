# House of Tiers

A single-page site for House-Of-Tiers custom cake business in White Rock, B.C.
Built with React + Vite + Tailwind CSS.

## Live Demo

*Not yet deployed — coming soon.*

## Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS (custom theme — colors, fonts, shadows in
  `tailwind.config.js`)
- **Form handling:** EmailJS

## Getting started

```bash
git clone https://github.com/eduardokdp/house-of-tiers.git
cd house-of-tiers
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

To build for production:

```bash
npm run build
```
